# Results

`benchmark.csv` is append-only and **tracked in git**: one row per evaluation
run, written by `scripts/run_baseline.py`. It is the shared record — if your
number is not here, it did not happen.

`table_<stamp>.{md,csv}` are dataset × method × metric tables generated by
`scripts/run_benchmark.py`. Keep the ones you cite; the rest are disposable.

Per-run detail (full config, environment, git commit, per-sample metrics,
timing) goes to `experiments/runs/<stamp>_<experiment>/`, which is **not**
tracked — regenerate it by re-running the experiment file.

Each row records the git commit and whether the tree was dirty. A row from a
dirty tree is not reproducible; do not cite one.
